# 📊 Discrete Calculator

A Java-based **Discrete Mathematics Calculator** designed to perform essential matrix operations through a structured and modular application.

The project focuses on applying mathematical concepts from **Discrete Mathematics and Linear Algebra** using Java, while keeping the code organized and easy to extend.

---

## 📌 Project Overview

Discrete Calculator is an educational Java application that provides a graphical interface for working with matrices and performing common matrix operations.

The project was developed to strengthen practical understanding of:

* Matrix representation
* Matrix operations
* Object-oriented programming
* GUI-based Java applications
* Modular code organization

---

## ✨ Features

* Create and work with matrices
* Perform operations on a single matrix
* Perform operations between two matrices
* Interactive calculator interface
* Built-in help section
* Structured Java classes for different application components

---

## 🧮 Matrix Operations

The calculator is designed around matrix-based operations commonly used in:

* Discrete Mathematics
* Linear Algebra
* Computer Science mathematics

The project separates matrix handling and operations into dedicated Java classes, making the application easier to maintain and extend.

## 📂 Project Structure

```text
Discerete-Calculator/
│
├── Matrix.java
├── Operation_1matrix.java
├── Operation_2matrix.java
├── btn_help.java
├── help_content_panel.java
├── home_panel.java
├── opreation_panel.java
└── the_Calculator.java
```

### Main Components

| File                      | Purpose                                                     |
| ------------------------- | ----------------------------------------------------------- |
| `Matrix.java`             | Handles matrix representation and core matrix functionality |
| `Operation_1matrix.java`  | Handles operations involving a single matrix                |
| `Operation_2matrix.java`  | Handles operations involving two matrices                   |
| `the_Calculator.java`     | Main calculator interface                                   |
| `home_panel.java`         | Main/home interface panel                                   |
| `opreation_panel.java`    | Operations interface                                        |
| `btn_help.java`           | Help button functionality                                   |
| `help_content_panel.java` | Help content interface                                      |
